# OriginBot-Diana (Android)

Experimentelles Android-Projekt für eine manuell gestartete Kampfsteuerung in The Seven Deadly Sins: Origin. Keine Queststeuerung.

## Status
Grundgerüst. **Noch keine fertige APK und keine zuverlässige Diana-Bosserkennung.** Der Android AccessibilityService kann Bildschirmgesten ausführen, sobald der Nutzer ihn in den Systemeinstellungen aktiviert. Eine intelligente Erkennung von Angriffen, Ausweichfenstern oder Fähigkeiten ist noch nicht implementiert.

## Sicherheit
Die Bedienungshilfe hat weitreichende Berechtigungen. Aktiviere sie nur, wenn du dem selbst erstellten Projekt vertraust. Automatisierung kann gegen Spielregeln verstoßen.

## Build
Mit Android Studio öffnen, Gradle synchronisieren und APK bauen. Mindestversion Android 8 (API 26). Java 17.

## Nächste Schritte
Bildschirmauflösung und Layout aufnehmen, Koordinaten für Angriff/Ausweichen/Fähigkeiten konfigurieren, Testmodus hinzufügen und Erkennung der Bossanimationen entwickeln.
